not as another generic task tracker.

## Hacker News / Reddit Body

```text
Personal Task Assistant is a small OSS app for coordinating work between a human and an AI agent.

It ingests or receives tasks from external context, assigns owner/priority/DD, surfaces agent-ready work, and keeps human decisions or reviews separate. The repo includes a FastAPI app, local installer, JSON API, public examples, and a reference Telegram polling adapter.

The goal is not to replace Jira, Asana, YouTrack, Slack, Telegram, or email. Those tools stay sources of context. Personal Task Assistant is the layer where the human and agent agree on what happens next.

Feedback wanted: adapter design, agent lifecycle, onboarding, and what a trustworthy human/AI work queue should expose.
```
